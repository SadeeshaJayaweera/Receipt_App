# Pull Request 25: Product / Flavour Management UI Redesign

## Title
`feat(flavours): production-ready Material UI menu management with live stock toggles, category filtering, and accessible dialogs`

## Overview
This PR completely overhauls the juice flavours and menu inventory user experience using Material UI. It elevates `frontend/src/pages/Flavours.jsx` with real-time stock availability switches, multi-attribute search and category filters, responsive table and grid layout modes, an accessible Add/Edit modal dialog with validation, soft-archive confirmation dialogs, and instant optimistic UI updates via an enhanced `flavourStore`.

## Key Changes
1. **Flavour Store Extensions (`frontend/src/store/flavourStore.js`)**:
   - Added optimistic stock toggle method (`toggleAvailability(id)`) that toggles local state immediately and reverts safely on server errors.
   - Added soft-delete support (`archiveFlavour(id)`) and menu reactivation (`restoreFlavour(id)`).
   - Added permanent delete method (`deleteFlavour(id)`).
   - Standardized error state handling and clearing.

2. **Material UI Flavours Management (`frontend/src/pages/Flavours.jsx`)**:
   - **Header & Metrics**: Top title with store overview and 4 KPI summary cards (Total Flavours, In Stock & Available, Out of Stock, Menu Categories).
   - **Advanced Search & Filtering Toolbar**: Real-time search across flavour names, SKUs, and descriptions; category dropdown (Fresh Juice, Smoothie, Milkshake, Mocktail, Special Drink); availability status filter; "Show Archived" toggle; and Table vs Grid view switcher.
   - **Inventory Table**:
     - Visual drink avatars with item names and SKU chips.
     - Color-coded category chips.
     - Currency-formatted retail prices (`formatCurrency(price, currency)`).
     - Live stock availability switch directly in table rows with tooltip explanations.
     - Status badges (`In Stock`, `Out of Stock`, `Archived`).
     - Quick action buttons for editing, archiving, restoring, and deleting.
   - **Responsive Grid View**: Optional card view with status borders, badges, stock toggles, and edit/archive buttons.
   - **Add & Edit Modal Dialog**:
     - Name, non-negative price, SKU/code, category selector, multiline description, and initial stock switch.
     - Inline client-side validation and store error alert banner.
   - **Archive & Delete Confirmation Dialog**:
     - Safe confirmation preventing accidental deletions, with soft-archive semantics for active items and permanent removal for archived items.
   - **Modernized FlavourForm (`frontend/src/components/FlavourForm.jsx`)**:
     - Backwards-compatible standalone component updated to clean Material UI components.
