# Pull Request 19: PDF Receipt Generation Redesign

## Title
`feat(pdf): professional 80mm receipt generation engine, dynamic layout scaling, and multi-currency formatting`

## Overview
This PR completely redesigns receipt PDF generation across both backend and frontend layers. It replaces rigid, hardcoded fixed-dimension layouts with a dynamic, non-clipping 80mm continuous receipt generation engine. The PDF output now dynamically scales based on line item count, customer profile, discount/tax calculations, and custom store branding while respecting multi-currency formatting rules (`LKR` and `USD`).

## Key Changes
1. **Backend PDF Generation Service (`backend/src/services/pdfReceiptService.js`)**:
   - Developed `PdfReceiptService` using `pdfkit` targeting 80mm standard receipt paper width (`226.77 pt`).
   - Implemented dynamic height calculation (`calculateReceiptHeight`) to prevent clipping or forced awkward multi-page splits.
   - Incorporated business branding from user profile (`businessName`, `address`, `phone`, `email`, and `receiptFooter`).
   - Added visual notices for non-standard receipts (`*** VOIDED RECEIPT ***` and `*** DRAFT RECEIPT ***`).
   - Clean tabular formatting for items: left-aligned names, centered quantities, right-aligned subtotal figures.
   - Comprehensive totals breakdown: Subtotal, Discount, Tax (if enabled), and Grand Total.
   - Payment method details, tendered cash, and change given calculations.
   - Provided both streaming response support and `generateReceiptPdfBuffer` for programmatic generation.

2. **Controller Integration (`backend/src/controllers/receiptController.js`)**:
   - Replaced legacy hardcoded logic in `GET /api/receipts/:id/pdf` with delegation to `pdfReceiptService`.
   - Injected business profile metadata fetched from the authenticated user.

3. **Frontend Unified PDF Utility (`frontend/src/utils/pdfGenerator.js`)**:
   - Implemented a unified `jsPDF` engine (`generateReceiptPdf`, `downloadReceiptPdf`) sharing the identical 80mm design system.
   - Eliminated over 250 lines of duplicate, hardcoded jsPDF code across `CreateReceipt.jsx` and `Receipts.jsx`.
