# Pull Request 21: Business Branding & Receipt Customization

## Title
`feat(branding): store branding profiles, receipt customizer, custom prefixing, and interactive preview`

## Overview
This PR completes Phase E (Professional Receipt Output) by providing multi-tenant business branding and receipt customization. Store owners can customize their storefront identity, slogans/taglines, contact information, social links, logo emojis, sequential numbering prefix (`RCP`, `POS`, `INV`), customizable thank-you/return policies, tax rates, and default currencies with a real-time side-by-side 80mm preview.

## Key Changes
1. **User Schema & Validation Enhancements (`backend/src/models/User.js` & `backend/src/validators/authValidators.js`)**:
   - Added schema fields with safe defaults:
     - `tagline`: Store slogan printed in header.
     - `website`: Store website or social URL.
     - `receiptPrefix`: Custom receipt sequence prefix (e.g. `POS`, `INV`, max 8 uppercase chars).
     - `logoIcon`: Store icon or emoji badge (e.g. `🧃`, `🍹`, `🥤`).
     - `showLogo`: Toggle for logo visibility.
     - `showCustomerInfo`: Toggle for customer info visibility.
   - Hardened `updateProfileSchema` to enforce type safety, trimming, and bounds.

2. **Auth & Receipt Services (`backend/src/services/authService.js` & `backend/src/services/receiptService.js`)**:
   - Updated `authService.getProfile()` and `authService.updateProfile()` to expose and update branding metadata.
   - Injected tenant's custom `receiptPrefix` into atomic receipt number generation.

3. **PDF & Thermal Output Rendering (`backend/src/services/pdfReceiptService.js` & `frontend/src/utils/thermalPrinter.js`)**:
   - Formatted store tagline, website, and logo iconography in the receipt header across both PDFKit (backend) and ESC/POS thermal printer engine (frontend).

4. **Settings Page Overhaul (`frontend/src/pages/Settings.jsx`)**:
   - Built a tabbed configuration experience:
     - **Business Profile**: Store name, tagline, phone, address, website, and email.
     - **Receipt Customization**: Default currency, receipt prefix, logo emoji picker, custom footer note, and tax configuration.
   - Embedded a live interactive 80mm preview using `ReceiptThermalPreview` that updates in real time.
   - Added 1-click **Test 80mm Print** and **Download PDF** actions for immediate hardware verification.
