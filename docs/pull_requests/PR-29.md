# Pull Request 29: Business Settings & Branding UI

## Title
`feat(settings): modernized Material UI business settings and branding management with live 80mm thermal preview`

## Overview
This PR completely overhauls the Business Settings interface (`frontend/src/pages/Settings.jsx`) with Material UI and integrates it into `AppLayout`. It replaces the legacy Tailwind form with an intuitive, 4-tab configuration center covering Store Profile, Receipt Branding, Currency & Tax Options, and Printing Setup. Cashiers and store owners can configure company metadata, choose from quick-pick drink icons, customize sequential receipt prefixes, set tax percentages, test print 80mm thermal slips, and view real-time changes rendered on an interactive 80mm thermal receipt preview.

## Key Changes
1. **Material UI Settings & Branding Center (`frontend/src/pages/Settings.jsx`)**:
   - **Store Profile Tab (`StoreIcon`)**:
     - Business / Store Name (required validation)
     - Tagline or Slogan
     - Telephone / WhatsApp contact
     - Website or social media handle
     - Multiline physical store address
   - **Receipt Branding & Customization Tab (`ReceiptIcon`)**:
     - Quick-pick drink logo icon selector (🧃, 🥤, 🍹, 🍊, 🍋, 🍍, ☕, 🍉)
     - Print Brand Icon toggle switch
     - Print Customer Details toggle switch
     - Sequential receipt number prefix editor (2-8 uppercase characters, e.g. `RCP`, `JUICE`)
     - Custom receipt footer message
   - **Currency & Tax Management Tab (`MoneyIcon`)**:
     - Default operating currency selector (`LKR` vs `USD`)
     - Sales Tax / VAT toggle switch
     - Configurable tax percentage rate (%) with validation (0-100%)
   - **Printing Setup Tab (`PrintIcon`)**:
     - Thermal paper roll selector (80mm standard continuous roll vs 58mm compact)
     - Auto-print on checkout toggle
     - Direct "Print Test 80mm Receipt" action button via `printThermalReceipt`
     - Direct "Download Sample PDF" action button via `downloadReceiptPdf`
   - **Interactive Live 80mm Thermal Receipt Simulation**:
     - Sticky preview card rendering `ReceiptThermalPreview`
     - Dynamically reflects changes to business name, tagline, address, logo, currency, tax, and prefix in real-time.
   - **Action Bar & Feedback**:
     - Header and footer Save Settings buttons with loading spinner.
     - Auto-dismissing success banner and inline error alerts.
