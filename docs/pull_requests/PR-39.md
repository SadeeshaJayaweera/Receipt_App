# Pull Request 39: Operational Documentation & Runbooks

## Title
`docs(ops): production operational runbooks, disaster recovery, incident management, and 80mm thermal printer setup guide`

## Overview
This PR provides comprehensive, production-grade operational runbooks and disaster recovery procedures (`docs/operations/`). It equips systems administrators, DevOps engineers, and retail store operators with structured guides for deploying, scaling, backing up, recovering, and maintaining the platform and thermal receipt printing peripherals.

## Key Changes
1. **Production Deployment Runbook (`docs/operations/DEPLOYMENT_RUNBOOK.md`)**:
   - Outlines hardware prerequisites (2 vCPU, 2GB RAM, Node 20 LTS, MongoDB 7.0+).
   - Provides complete environment variable inventory with Zod fail-fast requirements.
   - Details Docker Compose production deployment commands with health check status validation.
   - Details cloud hybrid deployment (Vercel SPA frontend + Render/Railway API + MongoDB Atlas Replica Set).
   - Specifies zero-downtime rolling update instructions.
   - Includes a post-deployment smoke testing checklist covering liveness, readiness, auth, and printing.

2. **Incident Response & Disaster Recovery Runbook (`docs/operations/INCIDENT_RUNBOOK.md`)**:
   - Defines a 4-tier Incident Severity Matrix (SEV-1 through SEV-4) with response and resolution SLAs.
   - Provides diagnostic playbooks for:
     - 502/503 service outages.
     - Database disconnection and connection pool saturation.
     - High CPU and memory leak spikes.
   - Details automated backup procedures with RPO < 1 hour and RTO < 30 minutes.
   - Provides full `mongodump` and `mongorestore` recovery commands.
   - Documents emergency JWT secret rotation playbook with automatic stale session termination.

3. **80mm ESC/POS Thermal Printer Operational Guide (`docs/operations/PRINTER_SETUP_GUIDE.md`)**:
   - Lists verified compatible printer hardware (Epson TM-T20/T88, Star Micronics TSP143, Rongta/Xprinter).
   - Step-by-step driver installation and paper cut configuration for macOS CUPS and Windows POS drivers.
   - Browser print dialog configuration (margins: None, background graphics: on, headers/footers: off).
   - Explains hidden iframe architecture and 72mm printable width constraints in `frontend/src/utils/thermalPrinter.js`.
   - Troubleshooting runbook for blank receipts, cut-off margins, auto-cutter jams, and print spool latency.

4. **Automated Documentation Verification (`backend/tests/operationsDocs.test.js`)**:
   - Automated tests ensuring all three runbooks exist, contain required structural sections, commands, and hardware specifications.
