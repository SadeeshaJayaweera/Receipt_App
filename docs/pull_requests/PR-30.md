# Pull Request 30: Accessibility, Keyboard Shortcuts & Responsive Polish

## Title
`feat(a11y): POS keyboard shortcuts engine, hotkeys help modal, skip-to-content links, and accessibility polish`

## Overview
This PR introduces enterprise cashier accessibility features and hotkey navigation across the application. Store cashiers can now navigate the POS system and execute operations entirely via keyboard shortcuts without needing mouse interaction. It adds a dedicated `useKeyboardShortcuts` hook, an accessible `KeyboardShortcutsDialog`, header hotkey triggers, screen reader "Skip to main content" skip links, and ARIA landmarks.

## Key Changes
1. **POS Keyboard Shortcuts Hook (`frontend/src/hooks/useKeyboardShortcuts.js`)**:
   - `F1` or `?`: Opens Keyboard Shortcuts & POS Keys modal guide.
   - `F2` or `Alt+N`: Instant navigation to POS / Create New Receipt (`/create-receipt`).
   - `F3` or `Alt+H`: Instant navigation to Receipt History & Audit Log (`/receipts`).
   - `F4` or `Alt+D`: Instant navigation to Business Dashboard & Analytics (`/dashboard`).
   - `F6` or `Alt+F`: Instant navigation to Flavours & Stock (`/flavours`).
   - `F8` or `Alt+T`: Toggle light / dark theme mode on the fly.
   - `F9` or `Alt+S`: Instant navigation to Store Settings & Branding (`/settings`).
   - `Esc`: Close open dialogs and modals.
   - Intelligently bypasses letter shortcuts while editing text inputs, but preserves POS function keys (`F1`-`F9`) for barcode scanner and cashier efficiency.
2. **Keyboard Shortcuts Guide Dialog (`frontend/src/components/KeyboardShortcutsDialog.jsx`)**:
   - Clean Material UI modal detailing hotkeys, descriptions, and category badges.
   - Monospace styled `<kbd>` keyboard key indicators.
3. **Application Layout Accessibility Enhancements (`frontend/src/components/AppLayout.jsx`)**:
   - Skip to main content link for screen reader and keyboard accessibility targeting `#main-content`.
   - Keyboard Shortcuts help icon button in top `AppBar` with tooltip.
   - `tabIndex={-1}` and `id="main-content"` on primary `<Box component="main">`.
