# Pull Request 28: Receipt History & Management UI

## Title
`feat(receipts): comprehensive Material UI receipt history with server pagination, advanced filtering, voiding audit flow, and dual-mode preview`

## Overview
This PR redesigns the Receipt History page (`frontend/src/pages/Receipts.jsx`) into an enterprise-grade administrative ledger and audit trail using Material UI. It connects directly with the backend's server-side pagination, regex search, date/status filtering, and voiding audit flow. Users can view key statistics cards, search across receipt numbers and customer names, filter by ticket status and payment method, inspect item breakdowns, view continuous 80mm thermal and standard invoice previews in `ReceiptPreviewModal`, trigger 80mm thermal printing and PDF generation, and securely void issued receipts with mandatory audit reasons.

## Key Changes
1. **Receipt History & Audit Ledger (`frontend/src/pages/Receipts.jsx`)**:
   - **Quick KPI Summary Cards**:
     - Total Records count
     - Issued Receipts count
     - Draft Tickets count
     - Voided Sales count
   - **Interactive Filtering & Search Bar**:
     - Debounced text search (matches receipt numbers, customer names, phone numbers, and line items)
     - Status selector (`All`, `issued`, `draft`, `voided`)
     - Payment method selector (`All`, `cash`, `card`, `online`, `other`)
     - Refresh button with loading feedback indicator
     - Quick "New Receipt" POS button linking to `/create-receipt`
   - **Material UI Data Table**:
     - Receipt number with click-to-preview
     - Formatted creation date and time
     - Customer information (name & phone badge or anonymous tag)
     - Total items badge
     - Minor-unit authoritative formatted total amount
     - Payment method chip
     - Distinct status chips (`Issued` success, `Draft` warning, `Voided` error)
     - Action icons:
       - View preview modal
       - Thermal print 80mm
       - Download PDF
       - Void receipt (guarded for issued receipts only)
   - **Server-Side Pagination Controls**:
     - MUI `TablePagination` integrated with `page` and `rowsPerPage` state, syncing with backend `limit` and `page`.
   - **Void Receipt Audit Dialog**:
     - Secure confirmation dialog requiring a non-empty audit explanation.
     - Submits reason to backend `POST /api/receipts/:id/void` via `receiptStore.voidReceipt`.
   - **Friendly Empty State**:
     - Displays illustration icon and call-to-action button when no receipts match criteria.
2. **Receipt Store Improvements (`frontend/src/store/receiptStore.js`)**:
   - Added `voidReceipt(id, reason)` method that dispatches void requests and updates local store state with audit status.
