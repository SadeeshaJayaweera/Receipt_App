# Pull Request 14: Customer & Transaction Information

## Title
`feat(receipts): structured customer profiles, payment transaction details, and customer search`

## Overview
This PR enhances the platform's receipt data architecture by introducing structured customer profiles (`name`, `phone`, `email`, `loyaltyNumber`, `notes`), transaction payment metadata (`method`, `cashReceived`, `changeGiven`, `reference`), seamless support for anonymous walk-in sales, and indexed search capabilities by customer phone and name.

## Key Changes
1. **Receipt Model Schema Enhancement (`backend/src/models/Receipt.js`)**:
   - Added `customer` subdocument:
     - `name`: string (trimmed, max 100)
     - `phone`: string (trimmed, max 30)
     - `email`: string (lowercased, trimmed)
     - `loyaltyNumber`: string (trimmed, max 50)
     - `notes`: string (trimmed, max 300)
   - Added `payment` subdocument:
     - `method`: enum (`'cash'`, `'card'`, `'mobile'`)
     - `cashReceived`: number (min 0)
     - `changeGiven`: number (min 0)
     - `reference`: string (e.g. card authorization code or mobile transfer ID)
   - Added compound indexes:
     - `{ userId: 1, 'customer.phone': 1 }`
     - `{ userId: 1, 'customer.name': 1 }`
   - Added bidirectional synchronization in `pre('validate')` ensuring full backward compatibility with legacy flat fields (`customerName`, `customerPhone`, `customerEmail`, `paymentMethod`).

2. **Receipt Service Operations (`backend/src/services/receiptService.js`)**:
   - Automatically computes `changeGiven` on cash payments using authoritative decimal calculations.
   - Preserves card/mobile transaction reference numbers.
   - Handles anonymous walk-in sales gracefully with clean zeroed defaults.
   - Enhanced `getAll(userId, query)` with search filters:
     - Filtering by customer phone (`customerPhone`).
     - Filtering by customer name (`customerName`).
     - Global search across `receiptNumber`, `customer.name`, and `customer.phone`.

3. **Controller & Validation Layer (`backend/src/controllers/receiptController.js` & `backend/src/validators/receiptValidators.js`)**:
   - Updated `receiptController.getAll` to forward `req.query` to `receiptService`.
   - Updated `createReceiptSchema` and `updateReceiptSchema` with nested `customer` and `payment` object schemas.
