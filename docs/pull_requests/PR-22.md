# Pull Request 22: Material UI Foundation & Theme System

## Title
`feat(ui): Material UI design tokens, responsive light/dark theme system, and ThemeProvider integration`

## Overview
This PR inaugurates Phase F (Frontend Redesign: Material UI & Modern UX). It installs Material UI (`@mui/material`, `@emotion/react`, `@emotion/styled`, `@mui/icons-material`), creates production-grade design tokens (`tokens.js`), establishes a unified light/dark theme engine (`theme.js`), and introduces `AppThemeProvider` with persistent theme switching and CSS baseline integration.

## Key Changes
1. **Dependency Installation**:
   - Integrated `@mui/material`, `@emotion/react`, `@emotion/styled`, and `@mui/icons-material` cleanly into `frontend/package.json`.

2. **Design Tokens Architecture (`frontend/src/theme/tokens.js`)**:
   - Defined core palette tokens:
     - Primary: Emerald green (`#10b981`, `#059669`) aligned with the beverage/juice brand.
     - Secondary: Amber gold (`#f59e0b`, `#d97706`).
     - Status: Success, warning, error, info colors.
     - Surfaces: Clean slate backgrounds (`#f8fafc` for light mode, `#0f172a` for dark mode).
   - Standardized component shapes (cards 12px, inputs/buttons 8px, chips 6px).
   - Unified system sans-serif and monospace typography stacks.

3. **Theme Engine & Component Overrides (`frontend/src/theme/theme.js`)**:
   - Built dynamic `getAppTheme(mode)` supporting `'light'` and `'dark'`.
   - Customized component styling:
     - `MuiButton`: `disableElevation: true`, `textTransform: 'none'`, rounded borders, micro-interaction scale feedback.
     - `MuiCard`: subtle mode-aware borders, soft elevation shadows.
     - `MuiOutlinedInput`: modern rounded focus rings.
     - `MuiTableHead`: subtle uppercase headers with elevated typography.
     - `MuiChip` and `MuiDialog`: sleek modern border radii.

4. **Theme Context Provider (`frontend/src/theme/ThemeContext.jsx`)**:
   - Provided `useThemeMode()` hook delivering `mode`, `toggleTheme()`, and `setMode()`.
   - Persisted theme preferences in `localStorage` (`receipt_app_theme`).
   - Synced with browser system preference (`prefers-color-scheme`).
   - Coordinated with `document.documentElement` class list for hybrid Tailwind CSS dark-mode compatibility.
   - Wrapped React tree with `CssBaseline` and MUI `ThemeProvider` in `frontend/src/App.jsx`.
