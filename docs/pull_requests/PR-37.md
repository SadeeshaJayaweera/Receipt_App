# Pull Request 37: CI/CD Pipeline & GitHub Actions Verification

## Title
`ci(github-actions): automated continuous integration pipeline for backend, frontend, docker builds, and security sanity`

## Overview
This PR implements a production-grade Continuous Integration (CI) pipeline using GitHub Actions (`.github/workflows/ci.yml`). The workflow automatically verifies code quality, test execution, compilation, containerization builds, and secret compliance on all pull requests and pushes to `master` and `develop`.

## Key Changes
1. **GitHub Actions Workflow Configuration (`.github/workflows/ci.yml`)**:
   - **Triggers**: Monitors pull requests and pushes targeting `master` and `develop`.
   - **Concurrency Control**: Automatically cancels obsolete in-progress CI runs when new commits are pushed to the same branch.
   - **Job 1: `backend-test`**:
     - Sets up Node.js 20 with package-lock caching.
     - Executes `npm ci` and runs the complete test runner (`npm test`) covering all 138 backend unit and integration tests.
   - **Job 2: `frontend-test-and-build`**:
     - Sets up Node.js 20 with npm caching.
     - Runs the complete Vitest component and E2E browser user journey test suite (95 tests).
     - Validates production bundle generation via `npm run build` with `CI: true`.
   - **Job 3: `docker-build-verification`**:
     - Runs after test jobs succeed.
     - Configures Docker Buildx.
     - Builds multi-stage `backend/Dockerfile` and `frontend/Dockerfile` images to guarantee zero container packaging regressions.
   - **Job 4: `security-compliance`**:
     - Scans repository tree to ensure no live `.env` or credential files are inadvertently committed.

2. **Automated CI Workflow Verification (`backend/tests/ciWorkflow.test.js`)**:
   - Automated tests ensuring the workflow manifest exists, defines required branch triggers, and specifies all verification jobs.
