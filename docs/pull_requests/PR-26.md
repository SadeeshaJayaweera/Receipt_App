# Pull Request 26: Receipt Creation POS Workflow Redesign

## Title
`feat(pos): high-speed Material UI cashier point-of-sale terminal with fast-touch tiles, live cart computations, and payment tender`

## Overview
This PR completely overhauls the receipt creation experience into a modern, high-speed retail Point-of-Sale (POS) cashier terminal. It replaces legacy static inputs with an intuitive split-pane design in Material UI: a fast-touch product catalogue on the left with category tabs and real-time search, coupled with an interactive order ticket / cart on the right. Calculations are powered strictly by the authoritative financial engine (`calcEngine.js`), with live discount options (fixed or percentage), configurable tax handling, cash change calculation with quick-cash tender chips, draft saving, and instant 80mm thermal printing upon checkout completion.

## Key Changes
1. **Material UI POS Cashier Terminal (`frontend/src/pages/CreateReceipt.jsx`)**:
   - **Interactive Product Catalogue Grid**:
     - Fast-touch product tiles with beverage category icons, name, category badge, formatted price (`formatCurrency`), and live stock status.
     - Out-of-stock items are visually dimmed and protected from accidental selection.
     - Scrollable category tabs (All, Fresh Juice, Smoothie, Milkshake, Mocktail, Special Drink) and instant search by flavour name or SKU.
     - Currency toggle between LKR (`Rs.`) and USD (`$`).
   - **Interactive Order Ticket / Cart**:
     - Live item count and total subtotal calculation.
     - Line items with unit prices, quantity increment/decrement buttons (`+` and `-`), line item subtotal, and deletion button.
     - Quick "Clear Cart" button.
   - **Customer Details Section**:
     - "Walk-in Customer" fast toggle (defaults to anonymous walk-in).
     - Optional customer name and phone number fields when toggled off.
   - **Authoritative Real-Time Computations**:
     - Subtotal calculated using integer minor units via `calculateReceiptTotals`.
     - Flexible discounts: Toggle between fixed amount or percentage with automatic subtotal capping.
     - Configurable sales tax: Switch to toggle tax on/off with custom percentage rate input.
     - Grand total strictly matching backend decimal precision.
   - **Payment Tender & Cash Change Calculator**:
     - Payment tender selector: Cash, Card, Mobile / Digital Wallet.
     - Cash change engine: Calculates exact change or shortfall warning using `calculateChange(total, cashReceived)`.
     - Quick-cash chips: "Exact", "+50", "+100", "+500", "+1000".
     - Pre-checkout validation preventing issuance if cash received is less than total due.
   - **Dual Checkout Actions**:
     - "Complete & Issue Receipt": Finalizes sale with `status: 'issued'`, persists to backend, and opens success modal.
     - "Save as Draft Ticket": Saves order with `status: 'draft'` for later recall.
   - **Post-Checkout Success Dialog**:
     - Confirms receipt number, total, customer, payment method, and change given.
     - Instant one-click "Print 80mm Receipt" and "Download PDF" buttons.
     - "Start Next Order" button to quickly reset the terminal for the next customer.
