## PR-08: API Abuse Protection and Security Middleware

### Objective
Harden the HTTP boundary with industry-standard web application security protections: strict production CORS allowlists, Helmet security headers (CSP, HSTS, Sniff protection), rate limiting for brute-force mitigation on authentication endpoints, 1MB request-size limits, and NoSQL / prototype-pollution input sanitization.

### Existing problem
- CORS was configured with an insecure fallback (`else { callback(null, true); }`) that permitted any untrusted origin with `credentials: true`.
- Helmet was configured with relaxed settings that did not enforce strict CSP or HSTS headers.
- Request bodies accepted up to 50MB URL-encoded payloads without size constraints on JSON, leaving the server vulnerable to memory exhaustion DoS attacks.
- No rate limiting was enforced on `/api/auth/login` or `/api/auth/register`, exposing authentication endpoints to credential stuffing and brute-force password cracking.
- No input sanitization existed against MongoDB query selector injection (`$gt`, `$where`) or object prototype tampering.

### Implementation
1. **Strict CORS Allowlist:**
   - Enforced explicit origin validation against `config.FRONTEND_URL` and designated domains.
   - Denied arbitrary external origins in production.
2. **Helmet Security Headers:**
   - Enforced strict Content Security Policy (CSP), HTTP Strict Transport Security (HSTS) with 1-year max age, `X-Content-Type-Options: nosniff`, and `Cross-Origin-Resource-Policy`.
3. **Multi-Tier Rate Limiting (`backend/src/middleware/rateLimiter.js`):**
   - Global API limiter: 100 requests per 15-minute window with `RateLimit-*` standard headers.
   - Auth limiter: 10 attempts per 15-minute window for `/api/auth/login` and `/api/auth/register`.
4. **Request Payload Size Limits:**
   - Reduced maximum payload size to `1MB` for both JSON and URL-encoded bodies. Over-sized payloads are rejected with HTTP 413.
5. **Input Sanitization Middleware (`backend/src/middleware/sanitize.js`):**
   - Recursively strips keys prefixed with `$` and prototype-pollution keys (`__proto__`, `constructor`, `prototype`) across `req.body`, `req.query`, and `req.params`.
6. **Automated Security Verification Tests (`backend/tests/securityMiddleware.test.js`):**
   - Verified Helmet headers presence (`nosniff`, CSP, HSTS).
   - Tested NoSQL selector and prototype key stripping.
   - Verified 413 Payload Too Large rejection when payload exceeds 1MB.
