# Pull Request 27: Receipt Preview & PDF Experience

## Title
`feat(receipt-preview): interactive dual-mode ReceiptPreviewModal with 80mm thermal roll view, document invoice, and void security overlays`

## Overview
This PR creates a production-grade, highly versatile `ReceiptPreviewModal` component (`frontend/src/components/ReceiptPreviewModal.jsx`) built with Material UI. It features an interactive toggle between continuous 80mm thermal roll view and full-width A4/document invoice styling, real-time currency formatting, prominent VOID security watermarks and audit banners for voided receipts, draft notices, clipboard copy functionality, and direct one-click triggers for 80mm thermal printing (`printThermalReceipt`) and PDF export (`downloadReceiptPdf`).

## Key Changes
1. **Interactive Receipt Preview Modal (`frontend/src/components/ReceiptPreviewModal.jsx`)**:
   - **Dual-Mode Layout Toggle**:
     - **80mm Continuous Thermal Roll View**: Emulates physical receipt paper with 78mm width, monospace font, dashed boundary lines, drink icon header, customer metadata, itemized table, and payment breakdown.
     - **Standard Invoice Document View**: Modern SaaS invoice layout with clean bordered tables, business profile details, billing information, and right-aligned financial summary card.
   - **Security, Audit & Status Overlays**:
     - **Voided Status**: Bold diagonal translucent "VOID" watermark rendered across the receipt canvas, accompanied by a top red alert banner documenting the void reason, timestamp, and audit details.
     - **Draft Status**: Amber warning banner notifying cashiers that the ticket is in draft state and has not yet been issued.
   - **Action Bar**:
     - "Print 80mm Receipt": Calls `printThermalReceipt` via invisible continuous iframe.
     - "Download PDF": Calls `downloadReceiptPdf` to trigger client-side or backend PDF generation.
     - "Copy Summary": Copies a clean, monospace-formatted text summary of the receipt directly to the user's clipboard, with visual confirmation alert.
     - "Close": Modal dismissal.
   - **Authoritative Formatting**:
     - Strict adherence to minor-unit rounding and currency symbol resolution (`formatCurrency(amount, currency)`).
