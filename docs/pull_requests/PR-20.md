# Pull Request 20: 80mm Thermal Printing Optimization

## Title
`feat(printer): standardized 80mm ESC/POS thermal printing engine, print stylesheets, and responsive receipt preview`

## Overview
This PR modernizes thermal receipt printing for standard 80mm POS hardware. It introduces tailored print media queries (`@media print`), a dedicated printing utility (`thermalPrinter.js`) that uses background iframe printing to prevent intrusive popup blocker interferences, and a high-fidelity paper preview component (`ReceiptThermalPreview.jsx`).

## Key Changes
1. **80mm Print CSS Standards (`frontend/src/index.css`)**:
   - Defined `@page { size: 80mm auto; margin: 0; }` for continuous receipt roll printers.
   - Tailored `@media print` rules with 72mm printable width within 80mm paper roll boundaries.
   - Enforced high-contrast typography, monospace font stacks (`'Courier New', monospace`), and suppressed headers/footers/navigation.
   - Set `break-inside: avoid; page-break-inside: avoid;` to prevent unwanted mid-receipt page splits.

2. **Dedicated Thermal Print Engine (`frontend/src/utils/thermalPrinter.js`)**:
   - Implemented `generateThermalReceiptHtml`:
     - ESC/POS aligned geometry with clean dotted/solid/double dividing rules.
     - Business branding: store name, address, telephone, email, and receipt footer.
     - Multi-currency format integration (`LKR` / `USD`).
     - Line items table with truncated titles and aligned quantity/price columns.
     - Comprehensive financial breakdowns: Subtotal, Discount, Tax, Total, Tendered, and Change.
     - Prominent status banners for draft and voided receipts.
   - Implemented `printThermalReceipt`:
     - Utilizes an isolated hidden iframe for synchronous, non-blocking printing.
     - Bypasses browser popup blockers while offering a reliable fallback to dedicated popup windows if iframe print access is restricted.

3. **Receipt Thermal Preview Component (`frontend/src/components/ReceiptThermalPreview.jsx`)**:
   - Reusable on-screen preview reflecting the exact 80mm thermal receipt appearance.
   - Unified receipt previews across modal windows, POS screens, and creation flows.
   - Eliminated over 200 lines of brittle inline HTML string templates across `CreateReceipt.jsx` and `Receipts.jsx`.
