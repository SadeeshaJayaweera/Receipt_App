## PR-02: Testing and Code-Quality Foundation

### Objective
Establish reliable, automated testing infrastructure for both backend and frontend applications, providing automated test runners, API integration testing with Supertest, component testing with Vitest and React Testing Library, and unified root test orchestration scripts.

### Existing problem
- Backend had zero automated tests and no `test` script in `backend/package.json` (`npm test` returned `Missing script: "test"`).
- Frontend tests failed to execute due to uninstalled dependencies, CRA Jest 27 incompatibility with React Router v7 subpath exports, and Axios pure ESM import syntax errors.
- No unified script existed at root to run all test suites across the monorepo.

### Implementation
1. **Backend Testing Foundation:**
   - Configured Node.js native test runner (`node:test`, `node:assert/strict`) for backend.
   - Installed `supertest` for Express endpoint integration testing.
   - Guarded MongoDB connection in `backend/server.js` against process crashes when executing in `NODE_ENV=test`.
   - Created `backend/tests/health.test.js` validating `/api/health`.
   - Created `backend/tests/authMiddleware.test.js` validating missing token, invalid token, and valid JWT parsing.
   - Added `"test": "node --test"` in `backend/package.json`.
2. **Frontend Testing Foundation:**
   - Replaced fragile CRA Jest setup with `vitest` + `jsdom`.
   - Created `frontend/vitest.config.mjs` with jsdom test environment and `@testing-library/jest-dom` assertions.
   - Replaced template `App.test.js` with `App.test.jsx` verifying App render and unauthenticated redirect to Login.
   - Added `"test": "vitest run"` and `"test:watch": "vitest"` in `frontend/package.json`.
3. **Root Monorepo Orchestration:**
   - Configured `npm test`, `npm run test:backend`, and `npm run test:frontend` in root `package.json`.
   - Created `docs/testing/TESTING_GUIDE.md` detailing test commands, execution patterns, and authoring guidelines.

### Files changed
- `backend/package.json`: Added test script and devDependencies.
- `backend/server.js`: Conditional MongoDB connection in test mode.
- `backend/tests/health.test.js`: Health endpoint integration tests.
- `backend/tests/authMiddleware.test.js`: Auth middleware unit tests.
- `frontend/package.json`: Added vitest scripts and dependencies.
- `frontend/vitest.config.mjs`: Vitest configuration file.
- `frontend/src/App.test.jsx`: Updated App component test.
- `package.json`: Added root test scripts.
- `docs/testing/TESTING_GUIDE.md`: Comprehensive testing documentation.
- `docs/pull_requests/PR-02.md`: Formal PR record.

### Architecture impact
Introduced automated regression prevention across both client and server layers without introducing heavy or deprecated build tooling.
