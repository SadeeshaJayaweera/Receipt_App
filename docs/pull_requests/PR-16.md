# Pull Request 16: Receipt History & Advanced Search

## Title
`feat(receipts): server-side pagination, sorting, date/amount range filters, and multi-field search`

## Overview
This PR implements high-performance server-side pagination, multi-attribute sorting, date/amount range filters, status and currency filtering, and comprehensive full-text search across receipt history, returning standardized pagination metadata.

## Key Changes
1. **Server-Side Pagination & Metadata (`backend/src/services/receiptService.js`)**:
   - Implemented standard pagination parameters (`page`, `limit` with min 1, max 100).
   - Returns structured pagination metadata:
     - `total`: Total matching records.
     - `page`: Current active page.
     - `limit`: Current page size.
     - `totalPages`: Total number of pages.
     - `hasNextPage`: Boolean indicator.
     - `hasPrevPage`: Boolean indicator.
   - Added support for bypassing pagination via `paginate=false` or `all=true` (useful for exports and reports).

2. **Advanced Multi-Criteria Filtering**:
   - **Date Range**: Filter by `startDate` and `endDate` with automatic end-of-day handling.
   - **Amount Range**: Filter by `minAmount` / `minTotal` and `maxAmount` / `maxTotal`.
   - **Status Filter**: Strict matching against `draft`, `issued`, or `voided`.
   - **Currency Filter**: Strict matching on `LKR` or `USD`.
   - **Payment Method**: Filtering by `cash`, `card`, or `mobile`.
   - **Multi-Field Full-Text Search**: Case-insensitive regular expression search across `receiptNumber`, customer name, customer phone, notes, and line-item flavour names.

3. **Multi-Attribute Sorting**:
   - Supports sorting by `createdAt`, `totalAmount`, and `receiptNumber` in ascending or descending order.

4. **Frontend Store Integration (`frontend/src/store/receiptStore.js`)**:
   - Updated `useReceiptStore.fetchReceipts` to accept query filter parameters and store structured pagination state.
