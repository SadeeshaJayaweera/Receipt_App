# Pull Request 24: Business Dashboard UI Redesign

## Title
`feat(dashboard): comprehensive Material UI business dashboard with real-time sales KPIs, Recharts analytics, and flavour leaderboard`

## Overview
This PR completely redesigns the business dashboard using Material UI (MUI) components and interactive visual analytics. It wraps the dashboard in `AppLayout`, integrates with the backend analytics engine (`/api/analytics/dashboard`), introduces a dedicated `useAnalyticsStore`, surfaces real-time financial KPIs (Today, Week, Month, Total, AOV), renders Recharts daily revenue timeline and payment breakdown graphs, presents a top-selling flavours leaderboard, displays a recent receipts table with status chips, and provides a multi-currency toggle (LKR/USD) with robust loading skeletons and error resilience.

## Key Changes
1. **Analytics Store (`frontend/src/store/analyticsStore.js`)**:
   - Built a specialized Zustand store to manage real-time dashboard analytics state.
   - Handles multi-currency queries (`fetchDashboard(currency)`), loading indicators, and error feedback.

2. **Material UI Business Dashboard (`frontend/src/pages/Dashboard.jsx`)**:
   - **Header Banner**: Store manager greeting, active business name resolution, fast currency switch (`ToggleButtonGroup` for LKR/USD), animated refresh action, and primary "New Receipt" POS launch button.
   - **Primary Financial KPIs**: 4 elevated cards with accent borders for Today's Revenue (with today's receipt count), Week's Revenue, Month's Revenue, and All-Time Revenue.
   - **Operational Metrics**: 4 operational cards for Average Order Value (AOV), Total Transactions (with issued, draft, voided breakdown), Active Menu Flavours, and Success Completion Rate.
   - **Visual Analytics Section**:
     - **Revenue Timeline (Daily Sales Trend)**: Recharts `AreaChart` with smooth gradient area fill, custom date formatting, responsive axes, and formatted tooltip.
     - **Payment Method Distribution**: Recharts `PieChart` with custom legend and method breakdown (Cash, Card, Digital Wallet).
   - **Leaderboard & Activity**:
     - **Top-Selling Juice Flavours Leaderboard**: Ranked flavour cards with sales quantity chips, revenue earnings, and relative progress bars.
     - **Recent Receipts Activity Table**: Monospace receipt numbers, customer names, payment method indicators, color-coded status chips (`issued`, `draft`, `voided`), formatted amounts, and quick link to `/receipts`.
   - **Quick Management Launchpad**: 4 interactive navigation tiles linking directly to POS cashier checkout, flavours inventory, receipt history, and store settings.
   - **Resilience & Loading States**: Skeleton placeholders during initial load and manual refresh; Material UI error banner with retry capability when network issues occur.

3. **JSDOM Polyfill & Test Environment (`frontend/src/setupTests.js`)**:
   - Added `ResizeObserver` polyfill to ensure charts render reliably across headless JSDOM environments.
