# Pull Request 23: Application Layout & Navigation Redesign

## Title
`feat(layout): responsive Material UI AppLayout, persistent sidebar drawer, and top AppBar suite`

## Overview
This PR delivers a production-grade SaaS application layout using Material UI. It introduces `AppLayout.jsx` featuring a responsive dual-mode navigation system (permanent desktop sidebar drawer and temporary collapsible mobile drawer), an elevated top `AppBar` with breadcrumbs, theme toggler, user profile avatar menu, and clean route highlighting. It also upgrades `Navbar.jsx` with full MUI design parity to ensure seamless compatibility with existing views.

## Key Changes
1. **Material UI Application Layout (`frontend/src/components/AppLayout.jsx`)**:
   - **Persistent Desktop Drawer (`md`+)**: 260px sidebar featuring the store logo badge, business name, and store tagline.
   - **Responsive Navigation List**: Clean navigation items for Dashboard, POS / New Receipt, Flavours & Stock, Receipt History, and Store Settings with icons and active route highlighting.
   - **Collapsible Mobile Drawer (`< md`)**: Accessible slide-out drawer triggered via the top hamburger button.
   - **Top AppBar**:
     - Active page title and breadcrumb navigation.
     - Dark/Light mode toggle button synced with `useThemeMode()`.
     - User account avatar with dropdown menu displaying business name, email, store profile shortcuts, and logout action.
   - **Content Container**: Responsive content box with 64px header offset and balanced padding.

2. **Navbar Modernization (`frontend/src/components/Navbar.jsx`)**:
   - Refactored legacy Tailwind navbar to a sleek Material UI `AppBar` and `Drawer`.
   - Maintained full backwards-compatibility with pages importing `<Navbar />`.
   - Utilized React 19 / MUI v6 standard `slotProps` for smooth DOM rendering without console warnings.
