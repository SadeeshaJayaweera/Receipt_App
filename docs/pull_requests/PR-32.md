# Pull Request 32: Backend Structured Logging & Audit Trails

## Title
`feat(logging): production-grade JSON structured logging, automatic credential redaction, and HTTP audit trails`

## Overview
This PR implements an enterprise-grade structured logging and audit engine for the backend (`backend/src/utils/logger.js` and `backend/src/middleware/requestLogger.js`). It replaces unstructured `console.log` calls with JSON-formatted log streams containing ISO 8601 timestamps, log severity levels (`debug`, `info`, `warn`, `error`), correlation IDs (`X-Request-Id`), request duration metrics, and automatic deep redaction of sensitive credentials and tokens.

## Key Changes
1. **JSON Structured Logger Engine (`backend/src/utils/logger.js`)**:
   - Standardized JSON formatting in production and test environments with metadata enrichment (`timestamp`, `level`, `message`, `requestId`, `userId`, `durationMs`).
   - Deep recursive credential sanitizer (`redactObject`):
     - Automatically scrubs `password`, `token`, `authorization`, `secret`, `cookie`, `creditCard`, `jwt` across objects, nested payloads, arrays, and Error details.
   - Dynamic level filtering (`debug`, `info`, `warn`, `error`) with standard output / error stream routing.
2. **HTTP Request Logging Middleware (`backend/src/middleware/requestLogger.js`)**:
   - Measures end-to-end request latency using high-resolution timers.
   - Listens to HTTP `res.finish` to capture method, path, status code, duration in milliseconds, correlation ID, and client IP.
   - Emits structured warnings on 4xx client errors and structured error logs on 5xx server errors.
3. **Integration with Central Error Handling & Database (`server.js`, `errorHandler.js`)**:
   - `errorHandler.js` logs 500 server crashes with full stack traces and correlation IDs, while logging 4xx operational validation errors cleanly without stack trace pollution.
   - Database connection state transitions (`connected`, `disconnected`, `error`) emit structured log events.
