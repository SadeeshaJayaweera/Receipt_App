# Pull Request 17: Business Dashboard & Sales Analytics

## Title
`feat(analytics): server-side sales analytics, revenue metrics, top-selling flavours, and payment breakdowns`

## Overview
This PR introduces a high-performance server-side analytics aggregation engine (`analyticsService`) and dedicated API endpoints (`GET /api/analytics/dashboard`). It delivers real-time business intelligence for retail operations, including period-based revenue summaries (today, week, month, total), average order value, top-selling flavours, payment method breakdowns, daily revenue timelines, and multi-currency segregation.

## Key Changes
1. **Analytics Aggregation Engine (`backend/src/services/analyticsService.js`)**:
   - Built multi-stage MongoDB aggregation pipelines:
     - **Revenue Metrics**: Computes `totalRevenue`, `todayRevenue`, `todayReceipts`, `weekRevenue`, `monthRevenue`, and receipt state counts (`issued`, `draft`, `voided`).
     - **Average Order Value (AOV)**: Exact decimal average order calculation for issued receipts.
     - **Top-Selling Flavours**: Unwinds line items and groups by flavour name, aggregating total quantity sold and revenue.
     - **Payment Method Distribution**: Groups by payment method (`cash`, `card`, `mobile`) to analyze tender shares.
     - **Daily Revenue Timeline**: 30-day grouped daily revenue trend.
     - **Multi-Currency Separation**: Segregates metrics by currency (`LKR`, `USD`) to preserve financial accounting standards.

2. **Controller and Routing (`backend/src/controllers/analyticsController.js` & `backend/src/routes/analyticsRoutes.js`)**:
   - Added endpoint `GET /api/analytics/dashboard` secured by JWT authentication.
   - Mounted modular analytics route in `backend/src/routes/index.js`.
